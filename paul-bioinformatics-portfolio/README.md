# Paul Alemoh Professional Portfolio

A polished React + Vite portfolio for bioinformatics and computer science work.

## How to run

```bash
npm install
npm run dev
```

Then open the local URL Vite gives you.

## Files to edit

- `src/App.jsx` — portfolio content, projects, skills, contact links
- `src/App.css` — design and layout
- `src/index.css` — global reset

## Customize

Replace:
- `your-email@example.com`
- `https://github.com/yourusername`
- Project descriptions/details as needed
